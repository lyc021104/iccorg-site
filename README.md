# ICC 官网复刻（九个栏目）

对 `https://icc.cffpd.org.cn` 的静态复刻，纯 HTML + CSS + 原生 JS，无构建、无依赖，九个页面可互相跳转，默认入口为证书查询页。

## 打开方式

- 直接双击 `index.html` 即可（已验证 `file://` 下页面与交互均正常）。
- 或在本目录运行 `python -m http.server 8765`，访问 <http://127.0.0.1:8765/index.html>。

## 页面

| 文件 | 页面 | 内容 |
| --- | --- | --- |
| `index.html` | 证书查询（默认入口） | 证书查询表单与说明 |
| `home.html` | 首页 | 全宽横幅、赛事介绍图文、证书查询、页脚 |
| `introduction.html` | 赛事介绍 | 两张整版设计长图，点击可放大查看 |
| `theme.html` | 竞赛主题 | 省级赛 9 项 + 主题赛 1 项主题卡片 |
| `announcement.html` | 通知公告 | 信息发布 / 资讯 / 通知筛选、公告列表、分页 |
| `organization.html` | 赛区组织 | 八大地区省市表格与主题赛「智能制造」 |
| `past.html` | 往届查询 | 省赛 / 线上主题赛筛选、往届结果列表、分页 |
| `download.html` | 模板下载 | 查新报告模板、发明日志模板及下载说明 |
| `contact.html` | 联系我们 | 技术咨询、联系电话、邮箱与两个官方二维码 |

顶部导航与移动端抽屉中的九个栏目均会真实跳转，并高亮当前页面。

## 交互说明（功能为演示）

原站功能依赖后端接口，本复刻只还原界面，部分行为做了无害的模拟：

- 导航、下拉、校验、弹窗、移动菜单、图片放大、标签筛选、模板下载均可正常操作。
- 证书查询在特定演示数据下显示国赛 / 省赛证书（见下表），其余组合提示「未查到证书信息」。
- 通知公告、往届查询只复刻了第一页数据；点击其他页码会提示「演示页面：仅复刻第一页数据」。
- 公告卡片点击后在新标签页打开对应的官方微信文章。
- 模板下载按钮下载的是官方原始 docx 文件（已保存到本地）。
- 个人中心、报名确认等入口以提示消息代替真实跳转，不会离开页面。

## 公网部署版本

本目录同时按公网演示版本准备：

- 页脚已移除备案号与公安图标，改为「非官方学习演示站点 · 与全球发明大会及主办方无关」
- 所有页面加入 `<meta name="robots" content="noindex, nofollow">`，根目录 `robots.txt` 禁止搜索引擎收录
- 站点为纯静态，可直接部署到 Cloudflare Pages / Vercel / Netlify 或任意静态服务器

Cloudflare Pages 部署示例（需先 `npx wrangler login`）：

```bash
npx wrangler pages project create iccorg --production-branch main
npx wrangler pages deploy . --project-name iccorg
```

部署后，在 Cloudflare Pages 项目的 Custom domains 中添加 `iccorg.top`，并按提示配置 DNS。
